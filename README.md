This contains all data and exported files from the CoE 199 undergraduate thesis project. 

- AS7343 Calibration - initial dyed water dataset used for characterization and initial calibration efforts for the AS7343 sensor

- Algal Samples - dataset of algal samples measured
  - Abs - raw measurements from AS7343 sensor converted to absorbance
  - Calibrated - calibration applied to raw absorbances (on Google Colab)
  - Calibration Models - exported models
  - Classification Models - exported models
  - Concentration Models - exported models
  - MSI Reference - reference readings of algal samples from MSI's spectrophotometer
  - Raw - all raw measurements from AS7343 sensor
  - per_ch - reorganized data per AS7343 sensor channel
